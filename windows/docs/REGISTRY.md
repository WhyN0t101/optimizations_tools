# Upstream registry items

Generated by `tools/build.py` from `upstream/zoicware/src/RegTweaks.txt` (ZOICWARE commit `2363922`) and the group mapping in the script. Do not edit by hand.

482 items in 192 groups. Each group runs when its option is on; the option of most groups is `Registry`. Leave one group out with `-SkipRegGroup '<group title>'` (wildcards work; `-ListRegGroups` lists them), or a whole option with `-Skip <Option>`. `-Revert` restores every value and key from the journal.

Notes: **policy** is a Group Policy value; Home and Pro ignore some of them, and the Edition area of `-HealthCheck` names those it knows. **Windows sets it itself** marks a value Windows writes back, which the health and revert checks treat as a note. **own option** marks a value with an option of its own instead of its group's. Some values are set again by a later step (telemetry, update and mouse options); the health check verifies them there.

What a group is for is its title, which upstream wrote; the values are listed so that you can look up any one of them.
