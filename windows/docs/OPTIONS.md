# FocusedTweaks options

Generated by `tools/build.py` from `$OptionInfo` in the template. Do not edit by hand.

88 options. Change them with `-Enable A,B`, `-Skip A,B`, `-Only A,B` or a profile (`-ProfilePath`).
Run `.\FocusedTweaks.ps1 -ListOptions` for the same list in the console.

## Software

| Option | Default | Undone by -Revert | What it does |

| `NvidiaProfile` | on | yes | NVIDIA GPUs only: import a low latency, maximum performance global profile with Profile Inspector (the driver settings are backed up first) |
